# Surika 专业知识记录

让用户能找回、理解和修正自己的专业记录。按[知识处理规则](references/memory.md)判断归属、依据和关系，用宿主已有的检索与文件工具处理用户指定的材料。

- **从会话提取。** 在当前可见范围内，保留用户希望沉淀的内容。材料只支持一条就留一条。若只有 Agent 的讲解而用户要求提取本人的判断，直接说明依据不足。
- **通过对话整理。** 从用户愿意讲的经历开始。只有某个未知细节会改变陈述的含义时才追问。用户自己的措辞已足够准确时，直接采用。
- **查询或修正。** 先定位相应记录。说明依据的深度依请求决定；纠正、删除时一并检查索引及引用该条记录的摘要和关系。

按请求交付候选内容或保存结果。仅预览时在对话中呈现；已要求保存且位置明确时直接操作。写入后核对实际记录和相关索引，简述改了什么、存在哪里。无法读取来源或写入时说明实际可见范围或保存状态。达到用户这次的目的即可结束。
