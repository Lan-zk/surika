# Surika Demo 实现 Prompt

状态：2026-11-12 用户授权按现有决策自主实现 Demo；忽略 Pi 提议。本文件是执行任务，不新增长期产品承诺。

## 目标

实现可运行的 Go + Viva macOS 学习应用，验证：一个不知道自己缺什么的 AI 编程者，能从问题或内置起点开始，通过解释、修改 Go 短程序、观察结果和追问积累理解；重启后能够延续探索。依据 `产品决策.md`、ADR 0002–0005、`学习记忆结构提案.md`，与旧报告冲突时采用新决策。

## 必须完成的闭环

1. 学习空间提供自由提问与“不确定，从一个例子开始”入口，不以考试或课程解锁作为前置条件。
2. 接入用户配置的 OpenAI 兼容 Chat Completions 网关：Base URL、模型、可选 Key、连接测试、流式输出、取消、清晰错误。允许显式内置体验，不能把固定脚本伪装成模型回答。
3. 首段内容围绕程序执行、变量赋值、函数输入输出。提供官方出处，课外 Go 问题按官方资料检索后组织回答；资料不足时承认不足。生成内容不自动成为审核教材。
4. 学习工作区包含可编辑 Go 实验、运行结果和继续追问。支持将模型生成的短程序带入实验；不自动执行。管理固定 Go 工具链并校验下载，不依赖或修改用户 Go 安装。
5. 限制实验包、代码大小、时间、输出、文件和网络访问；隔离不可用则拒绝运行，不用超时冒充隔离。不导入项目，不支持第三方依赖。
6. 在本机持久化对话、实验版本与结果、带来源的学习记录；区分讲授、自述、运行观察和推断。支持查看、修正，下次上下文使用修正后的记录；不设置掌握分数。
7. 界面以学习为中心：清晰起点、对话与实验、资料出处、记录与设置。没有模型时也能体验明确标注的基础示例。

## 实现裁剪

不采用 Pi；不实现多 Agent、任意插件、通用任务调度、知识图谱、账号同步、课程市场、用户导出或删除。模型使用普通对话与有界资料上下文即可，不预建通用 Agent 框架。以单进程 Go 应用和本地文件保存构建最小完整版本。具体布局、数据格式、错误处理与验证方案由实现者决定，无需继续提问。

## 验收

- 可构建并打开真实 macOS 窗口；内置起点 → 编辑 → 运行 → 讨论 → 查看记录 → 修正 → 重启恢复可操作。
- 用可控 HTTP 测试验证流式协议、错误、取消与上下文纠错；真实网关如无法使用，明确记录，不能冒充通过。
- 真实运行简单 Go 程序、编译错误、超时及隔离负例；不可执行被禁止代码。
- 数据读写错误不能静默吞掉或覆盖损坏数据；记录来源可以回查。
- 提供运行说明、已验收行为与 Demo 限制，不提交或推送未经要求的变更。
