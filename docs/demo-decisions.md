# Surika Demo 实现决策

本文只记录第一版 Demo 的实现选择，不新增或修改产品决策。产品目标仍以 `docs/产品决策.md` 和已确认 ADR 为准。

## 1. 单机 JSON 持久化

**Demo 选择：** 使用一个 `state.json` 保存会话、代码版本、运行结果、学习记录和设置，外层加 SHA-256 校验，保存采用同目录临时文件加原子替换。

**理由：** Demo 的数据量和并发模型足够简单，不需要数据库。校验可以区分损坏与空状态；加载失败时禁止覆盖原文件，保存失败时在界面持续提示并提供重试。

**边界：** 这是单进程本地 Demo 选择，不是多设备同步、备份或长期数据治理方案。

## 2. 规则驱动的学习记录与两阶段请求

**Demo 选择：** 讲授、用户自述、运行观察和有限推断由确定性规则从原始消息或运行结果生成。提问流程先检索官方来源，再将来源、近期经历和修正后的记录组装为上下文，最后流式请求模型。

**理由：** 不把“讲过”“赞同”或“运行成功”升级为“已掌握”，同时避免每轮额外调用模型做复杂记忆整理。每条记录保留来源消息或运行 ID，修正替换旧内容并保留原内容供回查。

**边界：** 当前推断规则刻意保守，不是完整的教学诊断系统。

## 3. 默认内置体验

**Demo 选择：** 新状态默认“仅使用内置体验”；用户明确关闭该开关并保存后才发送问题。默认填入本机 Magpie 地址和当前环境已验证可响应的模型名。

**理由：** 避免未配置模型时静默外发内容，同时保证没有模型也能体验课程、实验和记忆闭环。

**边界：** 默认地址与模型是本机 Demo 便利值，不代表未来产品必须绑定 Magpie 或某个模型。

## 4. 固定 Go 工具链

**Demo 选择：** 应用只管理 `go1.27.4`，按 macOS/架构固定官方文件大小和 SHA-256；下载使用 Go 官方页面的下载重定向域名 `dl.google.com`，失败后由用户重试。

**理由：** 不依赖或修改用户已有 Go 安装，下载校验与固定版本能缩小行为差异。直接连接官方下载域名避免了部分网络下 `go.dev` 前置 TLS 握手不稳定。

**边界：** 目前只覆盖 darwin/arm64 和 darwin/amd64 的固定校验值。

## 5. macOS 沙箱而非容器

**Demo 选择：** 使用 `sandbox-exec` 默认拒绝策略，只允许执行编译后的实验程序，禁止文件写入、网络和子进程，并通过路径解析处理 macOS `/tmp` 符号链接。隔离探测或执行失败时拒绝运行。

**理由：** 这是 Demo 所需的最小本地隔离方式，不需要额外守护进程或容器运行时。

**边界：** `sandbox-exec` 不是虚拟机，也不提供绝对安全保证。超时和输出上限不是隔离。

## 6. 最小资料检索

**Demo 选择：** 维护精简的 Go 官方来源目录，并尝试抓取 `go.dev/ref/spec` 的相关章节。检索失败时保留目录来源并明确警告，模型提示不得伪造引用。

**理由：** 满足 Demo 中“先有可靠依据再讲解”的最小流程，不建设通用搜索、索引或内容审核平台。

**边界：** 检索到来源不等于教学内容已经人工审核；当前来源集合只覆盖少量 Go 基础主题。

## 7. 单窗口学习界面

**Demo 选择：** 学习、学习记录、模型设置三个视图；学习视图固定为探索历史、教学对话、短实验三栏。

**理由：** 让“提问—观察—修正—继续”的上下文保持同屏，避免课程关卡、仪表盘和能力评分。

**边界：** 当前没有复杂窗口管理、移动尺寸适配或 `.app` 打包。

## 8. 不提供记录导出与删除入口

**Demo 选择：** 不实现学习记录和参考材料的导出或删除 UI。

**理由：** 当前 MVP 明确不包含这两类操作。直接修改 `state.json` 不属于受支持的产品流程，损坏时应用会拒绝静默覆盖。
