# 自由探索与引导并存，课程是支持路径

将 Surika 定位为有持续记忆、可信知识依据和教学能力的学习空间，允许用户自由探索，并在需要时提供连贯引导。课程路线是可调整、可偏离与返回的支持方式，不是必须解锁的关卡或应用唯一主线；Go 课程小样保留为教学验证场景，不据此扩大首版技术与主题范围。

此决定替代 [ADR 0001](0001-curated-curriculum.md) 将教学限制在预编排主线局部调整的产品定位。知识可靠性、AI 提议由应用检查、学习证据与模型评价分离仍然成立。

后续确认允许探索预设课程之外的 Go 问题：先查可靠资料，再组织教学；不确定处明确保留，生成内容不自动成为正式教材或掌握判断。具体检索与审核流程尚待设计。用户另行确认了动态 Go 短实验的受限执行，范围见 [ADR 0003](0003-managed-local-execution.md)，不扩展为任意项目执行。

相比固定课程驱动，这一选择增加了跨探索延续上下文、维持知识联系与处理内容边界的责任。教学可以邀请预测、实验或联系旧知识，但不把每次交流变成课程或测验；表达方式服从理解需要，不固定为 HTML、图示或问答。
