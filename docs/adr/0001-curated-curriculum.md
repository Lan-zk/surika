# 教学主线预先设计，AI 在边界内调整活动

2026-11-12 被 [ADR 0004](0004-free-exploration-with-guidance.md) 替代：不再把预编排课程作为应用唯一主线；可靠依据、应用检查和学习证据边界仍保留。以下保留原决策背景。

学习者不应承担自诊断和课程编排，但这不意味着把完整路线交给模型临时生成。采用经过核验的教学主线，由 AI 根据表现提议局部活动调整、应用检查后执行，以保留个性化帮助并约束内容漂移；学习证据与模型评价分开保存。

代价是必须先投入课程样本与验收依据的建设，无法靠通用聊天立即覆盖所有技术。调研支持这些设计机制存在，不证明它们对 Surika 已经有效；具体审核与评价校准仍待设计。依据见[产品决策](../产品决策.md)及[课程调研](../学习引导与课程组织_一手资料调研.md)。
