# 由应用管理本地 Go 实验环境

用户在远端执行与本地管理两种方案间选择本地执行，同时保留无需手动安装 Go 的使用目标。因此应用负责下载并管理固定版本工具链，首版运行内置课程和动态生成的 Go 短实验及其修改，不开放任意项目导入和第三方依赖。

2026-11-12 范围修订：用户确认自由探索也需要可运行实验，将此前仅限内置课程的范围扩展至动态生成的短实验。两类代码接受相同执行限制；不因有教学来源、由模型生成或能编译通过而视为可信。

这减少了对远端执行服务的依赖，但把工具链准备、进程与资源管理、权限隔离责任留给应用。隔离实现仍待核验；限制课程范围和设置超时都不能单独作为隔离保证。本决策不意味着已实现离线 AI 教学，模型仍经用户配置的网关访问。
