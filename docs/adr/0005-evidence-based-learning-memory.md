# 学习记忆可追溯、可修正，观察与推断分开

Surika 的记忆用于持续教学，不能把模型生成的摘要或讲授内容直接当成学习者掌握事实。采用经历可追溯、观察与推断分开、整理结果可修正、教学按需取用四条原则，避免以不断覆盖的单份摘要承担全部记忆职责。

代价是需要保留必要的来源关系与支持条件，并在推断修正后更新相关教学上下文；不能仅保存一个“已掌握”标签。教材知识的正确性与学习者的实际理解分别核验，未观察到不等于不会。

原始经历、观察、整理记录及本次上下文是结构提案，不预设四套存储。检索方式、整理时机、预算与数据库仍待决定。后续范围确认：用户导出与删除不纳入 MVP，查看与修正仍保留；这不意味着原始记录永久不可删除，也不取消内部纠错。具体讨论见[学习记忆结构提案](../学习记忆结构提案.md)。
