# 收敛为教学工作流与按需可视化设计

用户确认：Surika 是在通用 Agent 中使用的 skill，不是独立应用。它定义主要工作流和服务于学习目标的关键约束，保留用户自由探索与模型选择实现方式的空间。

## 决定

- skill 负责当前问题的教学帮助，不接管会话；用户可随时解释、练习、换题或回到开发。记录只服务于必要续接。
- 删除三个固定 HTML 模板与专用校验器，将教学活动参考合并，保留技术依据、学习证据与操作授权边界。
- 以 [DESIGN.md](../../skills/surika/references/DESIGN.md) 指导现场生成可视化，统一品牌配色、logo 使用、流程表达、动效与交互原则。随包保留品牌图片，不保留页面模板。
- 可视化服务于理解关系、变化与思路；用户要求或 Agent 判断有帮助时即可采用。静态图也是有效材料，不强制预测题、固定步骤、统一数据格式或 trace 回传。
- 实现和检查适配宿主与当前内容，不建设通用应用设施，也不以流程完成或材料数量证明学习效果。

## 替代与保留

本决定替代 ADR 0002、0003 的桌面交付与应用管理执行环境，以及 ADR 0006 中固定模板、数据契约和专用验收流程。保留自由探索、可修正学习记录、按需可视化和证据边界。历史研究、试点提案与截图保留为背景，不自动成为当前 skill 的需求。

可视化风格可辨识性与教学效果仍需实际使用观察；本次收敛不是效果验证。
