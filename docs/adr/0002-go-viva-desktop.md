# 首版采用 Go + Viva，先验收 macOS

首版选择 Go + Viva 桌面应用，而非此前建议的浏览器应用，以利用已有组件和项目经验，并围绕电脑上的读码、实验与学习构建闭环。先限定 macOS 验收；是否节省开发时间仍需实际验证，不能由组件存在直接推定。

该选择带来原生打包、框架版本及平台验证责任，首版不承诺移动端或链接即用。Viva 已有静态能力检查，但尚未固定依赖版本或完成学习页面组合验证；详见[产品决策](../产品决策.md)。
